# 회귀 분석 모델 · 이론 시뮬레이션

교과서 **110–113쪽(Ⅲ. 데이터 모델링과 평가 · 01. 회귀 분석 모델)**의 이론을 학생이 직접 움직여 보며 눈으로 확인하는 웹앱입니다. 실습 앱 [Data-Analysis_Regression](../Data-Analysis_Regression/)(114–121쪽)과 같은 디자인입니다.

## 실행

`index.html`을 더블클릭하면 됩니다. 설치나 인터넷 연결이 필요 없습니다(글꼴만 Google Fonts에서 받음). 웹에 올릴 때는 폴더의 파일을 모두 함께 올립니다.

## 구성

| 단계 | 교과서 | 시뮬레이션 |
| --- | --- | --- |
| 먼저 알아보기 | 110–113쪽 | 독립·종속 변수 예, 학습 순서 |
| 1. 독립·종속 변수 | 110쪽 | 독립 변수 고르기, 상관관계와 인과 관계 구분 |
| 2. 선형 회귀 | 111쪽 | 광고비·매출액 데이터에서 **손잡이를 끌어 직선 맞추기**(오차·오차 제곱 표), 오차의 합 대신 오차제곱합으로 비교하는 까닭(최소제곱법), 광고비·매출액 점을 찍어 회귀 직선 만들기 |
| 3. 상관관계 | 112쪽 | 상관관계 계수 슬라이더(점 50개), 끌 수 있는 이상치, 더 알아보기: **숨은 원인(기온)** 산점도 |
| 4. 오차 | 112쪽 | 오차 표현, 실젯값 끌기, **오차의 제곱을 넓이로 보기**, MAE·MSE |
| 5. 결정 계수 | 113쪽 | 흩어진 정도에 따른 R², SST·SSE 비교, 학습/평가 데이터 나누기 |

- 단계마다 연습문제가 3문항씩 있고, 3단계만 4문항입니다(총 16문항).
- 진행 상황은 브라우저 `localStorage`(`regression-theory-v1`)에 저장됩니다.

## 교과서와 다른 점 (교사용)

- 112쪽은 상관관계의 강도를 "직선의 기울기가 클수록 강한 상관관계"라고 설명합니다. 정확히는 점들이 직선 주위에 얼마나 모여 있는지로 판단합니다(단위를 바꾸면 기울기는 달라져도 r은 같습니다). 3단계에 '더 알아보기'로 보충했습니다.
- 숨은 원인, 결정 계수, 학습/평가 분할에 쓴 데이터는 시드를 고정한 **가상의 데이터**입니다.

## 파일

| 파일 | 내용 |
| --- |
| `index.html` | 페이지 뼈대 |
| `style.css` | 디자인 (세 이론 앱 공통) |
| `lib.js` | 공통 도우미: 표·카드·그래프 틀, 시드 고정 난수 (세 앱 공통) |
| `app.js` | 이 앱의 데이터, 시뮬레이션, 연습문제, 단계 |
| `core.js` | 화면 엔진: 단계 이동, 슬롯 갱신, 끌기, 진행률 (세 앱 공통) |

`lib.js`, `core.js`, `style.css`는 회귀·군집·연관 세 앱이 똑같은 파일을 씁니다. 공통 부분을 고칠 때는 세 폴더에 같이 복사하세요.
